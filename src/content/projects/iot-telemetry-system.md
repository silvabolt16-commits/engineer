An end-to-end telemetry system for machine condition monitoring. Sensors collect parameters such as temperature, vibration, and humidity, which are then sent via Wi-Fi/LoRa connection to the server.

The dashboard was created using Grafana to visualize time-series data, allowing the maintenance team to predict when a machine needs maintenance (Predictive Maintenance) before a fatal breakdown occurs.
