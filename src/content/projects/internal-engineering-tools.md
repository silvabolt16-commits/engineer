Stemming from the problem of manual document management and time-consuming calculations, this web portal was built as an internal initiative. This application digitalizes complex engineering calculation spreadsheets into an intuitive interactive web interface.

Its flagship features include auto-generation of industry-standard PDF report formats, and a dashboard for tracking P&ID revision progress. This proves that programming skills can solve real problems in the traditional engineering world.
